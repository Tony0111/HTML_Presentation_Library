# 演示模板制作与交付流程

本文负责从资料到交付的工作顺序。字段语法、章节调整与 AI 的具体修改规则见 [EDITING-GUIDE.md](EDITING-GUIDE.md)，工具环境与模块实现见 [TECH-STACK.md](TECH-STACK.md)。

所有命令均在要制作的演示目录内执行，而不是 Design 仓库根目录。

## 1. 建立独立演示

复制整个模板到新目录，保留母版。示例主稿名仍为 `content/sample.md`，后续直接替换其内容，不另建一份未接入编译器的主稿。

观看者只需要浏览器；制作内容需要 Python；运行浏览器验收和重建字体还需要技术栈文档所列的开发依赖。不要要求观看者安装这些工具。

## 2. 准备资料

先确定演示主题、受众、时间、章节顺序和用户要表达的判断，再准备文本、图表、图片、视频、单位与来源。

- 图表在制作阶段完成，进入模板的是本地 SVG / 图片，播放时不计算研究结果。
- 真实数据、文献观点、自己的理解与合成示例必须区分；资料不足时标记待补，不编造来源或数值。
- 所需素材复制到当前演示的 `assets/`，使用相对路径；不依赖母版外的素材库、个人路径或网络。
- 新素材须确认来源、再分发授权和离线可用性；保留需要随交付提供的许可证。

## 3. 整理主稿

由 AI 阅读修改指南后编辑 `content/sample.md`：先放封面和目录，再连续排列各章正文及最后一章的来源页，最后保留独立的 `thanks` 页。

每章第一页提供章 ID、中文章名和英文章名；同章后续页使用相同章 ID。章节数量不需要单独配置，编号、目录和折页数量随主稿生成。推荐 3-6 章，超过 8 章需重新设计。

内容只选现有页型；超量先精炼或拆页，不通过遮挡、截断或全局缩字号塞入。建议标题不超过两行、要点 3-5 条、表格不超过约 6-8 行；这些是审阅建议，不是编译器保证的容量。保留稳定页面 ID，用户可以按 ID 提修改意见。

## 4. 生成与检查

```bash
python tools/build_content.py
python test/tools/check_deck.py
```

第一条从主稿生成 `data/presentation.config.js`；第二条检查快照一致性、章节、素材和导航。遇到错误修正主稿或资源，再重新生成。不要直接修补生成文件。

新增中文字符或更换字体时运行：

```bash
python tools/subset_fonts.py
```

字体工具的源路径与许可要求见技术栈文档。缺少源字体或出现 `missing source` 时停止并报告，不能将末尾 `done` 当作成功；不随便换用商业字体。

## 5. 审阅与迭代

先打开 `review.html` 检查主题、页面顺序、章节归属、文字、素材路径和引用。再打开 `index.html` 检查实际视觉：标题断行、关键词、图例、单位、来源、页边装饰、粒子结束页和全屏。

用户通过页面 ID 提意见，例如：

```text
S04 标题保留前半句；S11 图注补单位；S09 的最后一个节点改为“复核来源”。
```

每轮修改主稿后都重新生成并检查整场，不只检查被修改页。内容修改使用 `check_deck.py`；改渲染代码则增加 `test/README.md` 所列的回归测试。旧示例中的固定页数和 ID 不是新文稿的约束。

## 6. 冻结与打包

内容确认后冻结页面顺序、章节、标题、数据、素材、来源和交互。随后：

1. 确认运行快照对应最新主稿，字体覆盖最终文字。
2. 移除新演示里确实未引用的素材；不要误删字体、图表、海报或许可证。
3. 需要时压缩图片和视频，但不改变研究图、单位、图例或数据含义。
4. 保留演示与审阅入口、主稿、快照、`js/`、`styles/`、`assets/`、`vendor/`、`LICENSES/` 以及制作说明。
5. 为后续可编辑交付，建议保留 `tools/` 和 `test/tools/`；仅给观看者的副本可省略开发工具，但母版保留。

无需构建前端包或下载运行依赖，不把整个上级 Design 仓库一起打包。

## 7. 离线验收与交付

将完成目录复制到另一个位置，断网直接打开 `index.html`，确认：

- 封面、目录、所有正文与 Thanks 能显示，图表没有拉伸和裁切。
- 每章选中与入口正确，非末章末页前进回目录，最后来源页前进到 Thanks。
- 上一页、临时目录返回、全屏、快速导航与减少动态模式正常。
- 视频由用户触发，默认静音，离页后暂停并回到起点。
- 字体、素材和许可随目录携带，没有网络或父目录依赖。
- 常用 16:9、16:10 以及需要使用的其他比例没有重叠；实际投影设备上能读清细字。

交付时记录章数、页数、入口、运行浏览器、执行过的检查和已知限制。未执行的环境或设备检查明确说明，不以桌面软件渲染测试替代真实设备验收。
