# 设计决策记录

> 记录已确认与待确认的设计决定。未确认项不得被当作已批准实现依据。

## D-01 项目名称

- 决定：文件夹与项目名称统一为 `presentation-template`。
- 理由：它是可复用的演示模板，不是某个视觉效果的文件夹。
- 状态：已确认。

## D-02 首版主题

- 决定：首版只有一套主题 `editorial-spatial`：暖白正文、墨黑舞台、砖红唯一主强调色，整体极简。
- 理由：先做透一套，其他主题放入其他模板。
- 状态：已确认。

## D-03 封面进入目录

- 决定：必须有空间感、立体感和连续观看路径；目录静止时也应有纵深，不是平面列表。
- 理由：极简不等于平面；这是本模板的核心体验。
- 状态：已确认（静态方向与开场分镜见 [STATIC-STORYBOARD.md](STATIC-STORYBOARD.md)、[OPENING-STORYBOARD.md](OPENING-STORYBOARD.md)）。

## D-04 演示素材定位

- 决定：`assets/imagery/` 中的两个 PNG 与两个 JPG 只是演示素材，不作为模板核心资产或设计前提。
- 状态：已确认。

## D-05 图表来源

- 决定：图表在制作阶段由独立工具完成，模板负责放置、播放与静态回退；播放阶段不内置通用浏览器绘图引擎，也不临时计算研究结论。
- 状态：已确认。

## D-06 正式渲染器

- 候选：DOM / CSS 3D；本地 Three.js。
- 决定：**本地 Three.js 作为唯一正式渲染器。**
- 理由：根据用户既有测试，Three.js 的空间效果更稳定；当前阶段优先把成果做出来，不再为更易实现但不够稳定的方案消耗时间。
- 约束：Three.js 只用于空间舞台（封面、目录、章节扉页、结尾）；正文、图表、表格、引用仍用 DOM，保证文字与数据的清晰、可选中和可访问。
- DOM / CSS 3D 版本保留在 `test/opening/` 作为测试对照，不被正式入口加载。
- 状态：**已确认**。

## D-07 内容工作流

- 决定：用户维护 Markdown 主稿，开发期工具生成运行快照；浏览器不 fetch 主稿，也不运行编译器；演示与审阅加载同一快照。
- 状态：已实现（P3）。

## D-08 字体

- 决定：随目录携带字体子集：Noto Serif SC（展示）、Noto Sans SC（正文）、DejaVu Sans Mono（数据）。
- 许可：Noto 字体为 SIL OFL 1.1（允许再分发），DejaVu 为 Bitstream Vera / 公有领域许可。许可证文本位于 `LICENSES/`。
- 生成：`python tools/subset_fonts.py` 按实际使用字符子集并输出 WOFF2。
- 约束：不打包无再分发许可的字体（如系统自带商业字体）。替换字体时先确认许可。
- 状态：已实现（P6）。

## D-09 交付边界

- 决定：交付为完整文件夹，包含演示入口、审阅入口、Markdown 主稿、运行快照、实际使用资产、许可、制作说明与测试证据。
- 决定：`test/` 下的历史截图与实验仅作证据，不参与运行时加载。
- 状态：已实现（P6）。

## D-10 亮色编辑式开场

- 决定：仅封面和目录改为亮色编辑风，暖白与浅灰构成版面，大面积砖红为主要视觉色；不沿用极简墨黑开场。
- 表达：立体印刷折页从封面的叠合状态展开成章节目录，保留纸面起伏、选章抬升与轻微指针视差；减少动态模式静止显示。
- 参考：Library 中 STLShaper Forms 的参数化形体、Hover Card Row 的立体抬升和编辑式字体层级；使用本地 Three.js 自行实现，不引用第三方图片。
- 边界：正文内容、结尾及既有键盘契约不变；新的开场样式限定在 `styles/opening.css`，场景限定在 `js/editorial-opening.js`。
- 后续修订：封面使用有间距的前后叠放，纸张颜色按砖红、暖白交替；移除 S03 / S07 / S12 / S20 旧路线图式章节页，目录直接进入 S04 / S08 / S13 / S21 正文，当前为 20 页。
- 状态：方向已确认；当前实现供视觉审阅。此决定仅覆盖 D-02 / D-03 中的开场视觉部分。

## D-11 章节回目录与双向转场

- 决定：移除旧黑色结束页 S24，当前 19 页；参考资料页作为末页保持停留。
- 导航：章内连续翻页，章末前进回到亮色目录并选中下一章，再由 Enter / Space 确认进入。手动打开目录仍保留原页返回行为。
- 动效：目录与正文往返采用 560ms 透视展开 / 收回与淡入淡出；快速导航可提前结束动画，减少动态模式直接切换。
- 边界：正文内容不改。此项覆盖此前跨章直接翻页及保留黑色结尾的约定。
- 状态：已按本轮需求实现。
