## 1. 目标与执行边界

将根目录的平面翻页原型与 `test/` 中分散的实验，整理为一套可复制、可离线播放、可由 Markdown 内容驱动的演示母版。

首版必须具备：

1. 唯一的 `editorial-spatial` 主题：暖白、墨黑、砖红。
2. 封面进入目录的连续空间转场，目录静止时也具有纵深，而非平面列表。
3. 章节、正文、数据、媒体与结尾属于同一套视觉语言。
4. 正文、图表、表格保持稳定阅读平面，不承受空间透视变形。
5. 用户通过 Markdown 和自然语言修改内容，不维护 JavaScript。
6. 文件夹复制到没有开发环境的电脑后，Chrome / Edge 直接打开 `index.html`。
7. BCI 的领域内容、波形与信号配色不进入通用母版。

不建设多主题切换、在线编辑器、演讲者视图、运行时 AI 服务或 PowerPoint 导出。不以页数或特效数量作为完成标准。

### 1.1 文档职责与冲突处理

| 文档 | 职责 | 处理原则 |
| --- | --- | --- |
| `DESIGN-DIRECTION.md` | 最新视觉与产品边界 | 首版设计约束，不恢复旧版多主题方向 |
| 本文 | 修改顺序、文件责任、验收 | 按阶段执行，确认后推进 |
| `REQUIREMENTS.md` | 场景和交互需求 | 沿用不冲突内容，冲突条目显式修订 |
| `CREATION-WORKFLOW.md` | 材料、图表、审阅、打包 | 保留用户准备图表、网页放置播放的工作流 |
| `TECHNICAL-ARCHITECTURE.md` | 旧空间屏风方案 | 参考资料，不直接作为新架构 |
| `README.md` | 实际运行状态 | 随阶段更新，不提前宣称计划功能可用 |

图表职责需要在实施前统一：已有图表不在网页中重画；`chart-focus` 承载预制 SVG、图片或本地交互 HTML。折线、柱状、散点是应验证的材料类型，不等于建设通用浏览器绘图引擎。确需生成图表时，在制作阶段由独立工具完成，保留数据与源码；不能在播放阶段临时计算研究结论。

## 2. 当前项目审计

以下根据当前文件内容判断，不根据旧 README 推断实现状态。

### 2.1 根目录实现

| 文件 | 当前情况 | 修改方向 |
| --- | --- | --- |
| `index.html` | 单一 `slide-stage`、背景装饰、常驻控制栏 | 等比画布、空间舞台、阅读舞台、轻量控制、错误层 |
| `styles/base.css` | 暖白全局背景、青绿强调、视口字号、封面圆环 | 重建统一变量、深浅角色、固定设计尺度，删除无角色装饰 |
| `js/app.js` | 渲染、导航、图表绘制混合；所有页横移淡入 | 分离内容、导航、渲染、媒体和动画生命周期 |
| `data/presentation.config.js` | 旧页型和人工配置 | 从 Markdown 生成运行快照，不再是第二份人工内容源 |

明确需要处理的问题：

- 目录是平面列表，没有章节跳转；`INDEX` 固定跳到第 2 页。
- `CLOSE INDEX` 只改标签，没有关闭目录和恢复原页的行为。
- 页脚与控制栏共用底部区域，有重复页码和遮挡风险。
- 章节编号由页面索引生成，不是稳定章节编号。
- `lines()` 匹配字面量 `\\n`，与配置中的真实换行不一致。
- 图表用固定数值到像素映射，没有完整的坐标、单位和范围契约。
- 全屏被统一动画锁挡住，请求失败没有反馈。
- 减少动态只影响 CSS，不改变 JavaScript 的固定锁定时间。
- 没有统一 16:9 等比画布；非 16:9 环境可能溢出。
- README 仍称入口是玻璃屏风原型，与当前运行代码不符。

这些问题在对应阶段解决，不继续给旧 CSS 叠加覆盖规则。

每阶段提交：修改文件清单、完成项、验收证据、遗留项。未达到通过条件，不用下一阶段功能掩盖问题。

执行动作：

### P1：八张静态样稿

目的：先确认画面，不开发运行时页型或动效。

新增 `design/STATIC-STORYBOARD.md`，逐页描述版式、内容、安全区、字体、视觉锚点和静态终态；同步制作静态图，存入 `design/frames/`。

| ID | 页型 | 必须验证 | 不能接受的替代 |
| --- | --- | --- | --- |
| S01 | `cover` | 大标题、前中远景、可追踪的砖红空间锚点 | 左文右圆环、标题卡片、随机粒子 |
| S02 | `contents` | 3–6 章沿空间路径排列，选中章清楚，远景可辨识 | 平面目录加阴影 |
| S03 | `section-divider` | 章节命题、真实编号、目录锚点延续 | 大标题和密集正文堆叠 |
| S04 | `headline-points` | 暖白阅读页，一个判断、三个要点 | 网页功能介绍卡片 |
| S05 | `split-media` | 材料主导，比例、图注、来源完整 | 四张占位 PNG / JPG 成为核心主题 |
| S06 | `chart-focus` | 坐标单位完整，单一重点、来源与示意标记 | 无刻度装饰曲线 |
| S07 | `process-flow` | 节点关系清楚，最终一次看全 | 用动画隐藏复杂关系 |
| S08 | `closing` | 回到同一空间锚点，收束并停留 | 自动回目录或重复播放 |

样稿规范：

- 1920 × 1080 设计画布，初始建议左右 120、上下 80 个设计像素安全边距，确认后固定。
- 12 栏编辑网格，独立来源区；标题、内容、页脚不重叠。
- 字号在画布内固定，整体等比缩放，不用 `vw` 调整字体；字距为 0。
- 起始字号建议：封面 140–200、标题 72–104、正文 30–38、图注 22–26。用中文长标题和投影阅读校验，不视为最终数值。
- 暖白正文不叠加持续动态或明显纸纹；墨黑舞台建立深浅节奏。
- 砖红是主强调色；数据系列用明暗、线型、点形和标签区分，不恢复青绿主题。
- 参考指向素材库具体路径，说明借鉴关系，不仅写“使用粒子”。
- 示例采用中性学习材料，合成数据明确标记，不冒充研究结果。

通过条件：八页联系表与单页大图确认，字体、边距、深浅分布和空间锚点写入决策记录。未确认前不改正式入口。

### P2：空间分镜与技术验证

目的：把已认可的静态关系变为连续、克制的空间动作。

新增 `design/OPENING-STORYBOARD.md`，明确：

1. 封面和目录是同一空间的两个观察位置，不是独立生成的场景。
2. 至少一个视觉元素延续全程，例如砖红路径或定位线，方向和形状可追踪。
3. 目录可以用前后错位的文字平面与节点组织，不未经确认恢复玻璃屏风。
4. 主标题与章节文字保持可读，不能因景深模糊必读信息。
5. 给出进度 0、0.25、0.5、0.75、1 的构图、位置、尺度、遮挡、透明度。
6. 开场目标 0.8–1.6 秒，正文不复用此镜头。
7. 定义返回、减少动态和渲染失败三种终态。

技术选择必须在分镜确认后进行：

| 方案 | 适用条件 | 选择依据 |
| --- | --- | --- |
| DOM / CSS 3D | 文字平面、路径、少量纵深层 | 字体清楚，静态回退简单，无复杂材质 |
| 本地 Three.js | 必要的几何遮挡、相机、空间对象 | CSS 3D 无法稳定实现已确认构图 |

只保留一个正式渲染器，另一种作为测试对照，不同时运行。Three.js 场景全幅呈现，不放进装饰预览卡片；正文仍用 DOM，研究图不变成场景纹理。

通过条件：冻结帧和录屏共同确认；目录静止时有纵深；减少动态仍可选章；渲染失败不阻断正文。

### P3：统一内容、画布和运行架构

目的：先建立可替换内容的骨架，再实施页型。

建议目录如下，只有确有职责时才创建模块，不先制造空文件：

```text
presentation-template/
  index.html                       正式演示入口
  review.html                      内容审阅入口
  content/sample.md                唯一人工内容主稿
  data/presentation.config.js      主稿生成的运行快照
  design/                          样稿、分镜、确认记录
  assets/fonts/                    打包字体
  assets/media/                    实际使用图片、视频
  assets/charts/                   已完成图表与回退图
  assets/manifest.js               资产角色、来源、许可记录
  styles/tokens.css                唯一主题、字级、网格
  styles/base.css                  重置、画布、安全区
  styles/slides.css                阅读页型
  styles/spatial.css               空间舞台
  js/content-model.js              内容、章节、引用、资产校验
  js/navigation.js                 页面与目录返回状态
  js/slide-renderer.js              阅读页型渲染
  js/spatial-stage.js               选定空间渲染适配器
  js/media.js                      媒体生命周期
  js/app.js                        初始化、统一输入与模块连接
  tools/                           开发期内容编译与打包
  test/                            实验、测试、证据
  vendor/                          实际采用的本地库
  LICENSES/                        字体、库、素材许可
```

执行动作：

1. 从测试模型抽取校验，统一新页型名；旧配置与测试 Markdown 不再并列为生产内容源。
2. 人工修改 `.md` 主稿，开发期工具生成普通脚本快照；浏览器不 fetch 主稿，不运行编译器。
3. 使用成熟 Markdown 解析器或明确限定的语法；正文不允许任意 HTML、脚本、eval。
4. 演示和审阅页加载同一快照；审阅显示页面 ID、文本、来源、材料路径和错误。
5. 画布固定 1920 × 1080，比例为 `min(视口宽 / 1920, 视口高 / 1080)`；16:10 补边，不拉伸材料。
6. 单一输入分发器负责导航；空间和正文模块不分别监听键盘。
7. 只保留当前页与转场所需相邻页；离场释放媒体、监听和动画实例。
8. 转场采用统一完成回调与兜底，不以短于 CSS 动画的定时器提前删页。

内容契约：

| 层级 | 字段 | 校验重点 |
| --- | --- | --- |
| 演示 | ID、标题、主题、章节、页序 | 主题固定 editorial-spatial |
| 章节 | ID、编号、标题、firstSlideId | 不用页面索引当章节号 |
| 页面 | ID、type、标题、章节或结构角色 | ID 唯一，未知页型报错 |
| 资源 | assetId、路径、替代说明、图注、来源 | 本地相对路径，缺失可定位 |
| 引用 | 来源 ID、作者 / 机构、标题、年份或待补状态 | 去重、按首次引用编号 |
| 流程 | 节点 ID、标签、起终点、条件 | 断链、重复 ID、容量校验 |

一次性迁移旧名称：section → section-divider，points → headline-points，quote / takeaway → statement，chart → chart-focus，process / flow → process-flow，toc → contents。旧 interactive 作为 chart-focus 的材料形式，不新增页型，不长期保留双命名。

通过条件：同一主稿生成一致配置；错误包含页 ID 与字段；替换标题、章数不改渲染代码；复制后无父目录依赖。

### P4：八页核心短演示

按 S01–S08 顺序实现已确认样稿，不继续探索第三套画面。

1. 正式入口接入新舞台，移除旧 ambient 装饰与重复页码。
2. 清理旧视口字号和覆盖样式；主题只由 tokens 控制。
3. 实现要点、图文、图表和流程；封面、目录、章节、结尾共享空间锚点。
4. 目录关联 firstSlideId，默认第一章；选中状态兼有位置、编号和砖红，不只靠颜色。
5. 研究图默认完整呈现；只有无需完整阅读的照片可明确配置裁切。
6. 图表加载预制材料；确需交互才加载本地库，并提供同数据静态回退。
7. 流程先支持横向 3–7 节点；超量要求拆页，不无限缩小文字。
8. 正文按语义块短揭示，一次前进翻一页，不逐条等按键。
9. 结尾保持停留，不自动返回或循环。

通过条件：八页完整连续播放；更换另一份中性内容稿不修改页面代码；整体像一场演示而不是组件画廊。

### P5：补齐首版能力

八页不等于完整首版，继续实现：

- statement：核心判断、限制与支撑，不增加近似的 quote / takeaway 页型。
- timeline：3–6 节点，区分真实时间和概念阶段。
- comparison / table-focus：语义化表格或并列条形，表头、单位、来源可配；删除 SESSION / STABILITY / LATENCY 硬编码。
- chart-focus：验证折线、柱状、散点预制材料的图例、单位、字体和静态阅读。
- process-flow：新增一个经样稿确认的简单分支布局，不承诺任意拓扑自动排版。
- video-focus：本地视频、封面、P / M、离场暂停重置、错误替代说明，无自动发声。
- references：短引、图注与参考页共享 ID；重排后编号一致；缺失来源标待补。

创建约 20–30 页、3–6 章的回归样稿。所有合成数据与占位来源可识别。参考过多拆页，不无限缩字。

通过条件：全部设计页型有样例，扩展后仍保持节奏；无 BCI 专属字段和领域硬编码。

### P6：验证、打包和交付

1. 执行第 8 节验证矩阵，正式入口必须纳入测试。
2. 内容与视觉冻结后确认字体许可、制作 WOFF2 子集，检查中文标点、数字单位和字重。
3. 只打包实际使用的素材和库；不因仓库已有就默认加入 Three.js、Anime.js 和 Plotly。
4. 字体、许可与回退资源随目录携带，不依赖本机字体或上级素材路径。

## 5. 导航与状态契约

状态包含：当前页 ID、当前章 ID、目录是否临时打开、选中章、原返回页、转场阶段、一次待处理动作、媒体状态、减少动态偏好。

| 状态 | 输入 | 行为 |
| --- | --- | --- |
| 封面 | Enter / Space / Right / Down | 推进到目录，默认第一章 |
| 目录 | Left / Right | 选相邻章，不循环 |
| 目录 | Home / End / 1–8 | 选首尾或存在的章 |
| 目录 | Enter / Space | 初次进入章首张；临时目录仍选原章回原页，改选进新章 |
| 目录 | Up / Backspace | 临时目录回原页；开场目录回封面 |
| 正文 | Right / Down / Space / PageDown | 下一页，跨章连续，不回目录 |
| 正文 | Left / PageUp | 上一页；首张正文前进入开场目录 |
| 正文 | Up / Backspace | 临时打开目录，记住原页和章节 |
| 正文 | Home / End | 第一张正文 / 结束页 |
| 视频 | P / M | 播放暂停 / 静音，不翻页 |
| 任意 | F | 全屏，动画中可用，拒绝有反馈 |
| 任意 | Escape | 仅退出全屏，不改页码 |

长按不跳多页；动画期间至多保留一次动作；焦点位于按钮、输入框或媒体时避免重复消费按键。iframe 转发必须验证消息来源，只接受预定义导航动作。

控制使用本地图标、可访问名称和悬停提示，尺寸固定；演示页不常驻功能说明和快捷键文字。页码只保留一套，工具栏不占来源区域。

## 8. 验证矩阵

开发期使用 Playwright；观看不需要安装依赖。不能仅测试 test/sample.html 就宣布完成。

| 维度 | 必测情况 | 判断 |
| --- | --- | --- |
| 视觉 | 八页终态、联系表、空间冻结帧 | 对照已确认样稿 |
| 视口 | 1920×1080、2560×1440、1440×900、1366×768 | 等比、补边、无滚动、无遮挡裁切 |
| 内容 | 长中文、长英文、单位、最大要点和表格行 | 不靠缩字号塞入；超量定位页 ID |
| 空间 | 五个进度、正向、返回 | 锚点连续、目录终态有纵深、正文不变形 |
| 回退 | WebGL 不可用、减少动态、后台恢复 | 非空白、可导航、不重置当前页 |
| 导航 | 全程、跨章、首尾、原页恢复、换章、快按 | 一键一次、结束页停留 |
| 媒体 | 图片缺失、视频坏文件与离场、交互图失败 | 路径与说明可见、仍可翻页、无残留声音 |
| 数据 | 三类图、表格 | 坐标、单位、图例、来源静态可读 |
| 引用 | 重复、重排、删页、待补 | 编号一致、不伪造来源 |
| 离线 | file://、阻断外网、复制目录 | 无远程请求、父目录依赖和主稿 fetch |
| 生命周期 | 翻页 50 次、目录往返、调整窗口 | 无事件重复、媒体残留、资源持续增加 |

截图存 test/shots/，结构化报告写 checks.json。错误配置负向测试单独记录，不与正常流程无 JS 错误混淆。

采用 Canvas / Three.js 时增加像素非空白检查，通过前后帧差异和对象状态确认实际移动。软件渲染通过不代表目标设备性能通过，投影设备需现场验证。
