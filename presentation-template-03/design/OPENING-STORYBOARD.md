# 开场空间分镜：封面 → 目录

> 状态：P2 初稿，待确认。
> 目的：把已确认的静态关系变成连续、克制的空间动作，并据此选择唯一正式渲染器。
> 原型：`test/opening/`；冻结帧与录屏证据：`test/opening/shots/`。
> 设计画布：1920 × 1080，16:9；焦距 1600px；镜头行程 2400 世界单位；开场目标 0.8–1.6 秒。

## 1. 空间模型

封面和目录不是两个独立生成的场景，而是同一空间的两个观察位置：

- 封面：镜头停在标题前方，标题是最大对象，目录停在远处。
- 目录：镜头前推后停在章节节点前，第一章最近最大，第四章最远最小。
- 全程延续的锚点是一条**砖红阅读路径**：它从封面标题下方的短横线出发，穿过远景，最终连接四个章节编号。
- 场景只有文字平面和一条路径，不使用红圆、尘埃、粒子、玻璃材质或全屏光效。

几何约定（共享投影，两种渲染器一致）：

```text
屏幕坐标 = 画布中心 + (世界坐标 - 镜头坐标) × (焦距 / 深度)
深度 = 世界 z - 镜头 z；深度越小，对象越大越近
```

## 2. 五个进度冻结帧

### p = 0.00 — 封面

- 镜头：z = 0，x ≈ 0。
- 标题「让判断 / 可见。」位于画面左中，是最大对象（世界 150px，屏幕约 160px）。
- 眉题在左上、副题在标题下方、署名在左下，均在安全区内。
- 阅读路径只显示起点短横线，从标题下方出发，指向画面右侧深处。
- 目录节点处于远景，极小、低对比，只作为空间提示，不抢标题。
- 目录透明度：0；封面透明度：1。
- 对应帧：`dom-p0.png`、`three-p0.png`。

### p = 0.25 — 前推开始

- 镜头：z ≈ 300，x 轻微向右摆动。
- 标题略微变大并向左下方移出视觉中心；封面保持不变的可读性，不使用模糊。
- 砖红路径开始延长，方向明确指向右上方的章节节点。
- 目录章节开始以很低透明度从远处显现。
- 封面透明度仍接近 1，目录透明度约 0.1–0.2。
- 对应帧：`dom-p0.25.png`、`three-p0.25.png`。

### p = 0.50 — 穿越中段

- 镜头：z ≈ 1200，x 达到最大摆动后回中。
- 标题因距离过近而离开画面并淡出；此时画面以空间和路径为主。
- 阅读路径成为显性对象，清楚连接各个正在靠近的章节编号。
- 四个章节按深度排列：第一章最大、第四章最小，纵深关系已经成立。
- 章节文字保持清晰，不做景深模糊。
- 封面透明度 ≈ 0.15；目录透明度约 0.4–0.6。
- 对应帧：`dom-p0.5.png`、`three-p0.5.png`。

### p = 0.75 — 目录就位前

- 镜头：z ≈ 1980。
- 封面完全退出，章节接近最终位置和尺度。
- 目录路径接近完整，编号与章节名可读。
- 当前章节（默认第一章）以砖红高亮。
- 对应帧：`dom-p0.75.png`、`three-p0.75.png`。

### p = 1.00 — 目录静止终态

- 镜头：z = 2400，x ≈ 0。
- 四个章节沿右上对角线排列，屏幕尺度约为 1.35 / 1.05 / 0.82 / 0.64，纵深明显。
- 第一节「01 问题 / THE QUESTION」最近最大，并以砖红强调；其余章节为暖白。
- 阅读路径完整连接四个编号，编号处有砖红节点标记。
- 目录静止时仍有纵深，不是平面列表。
- 曝光/透明度：全部章节 1；路径 1。
- 对应帧：`dom-p1.png`、`three-p1.png`。

## 3. 动效与节奏

- 开场时长目标 0.8–1.6 秒；原型默认 1.2 秒，缓动为对称 ease-in-out。
- 只有镜头前进、路径延伸和章节淡入三类动作，正文不复用该镜头。
- 同一时刻只有一个主要运动焦点：标题 → 路径 → 章节。
- 路径长度随进度推进（`stroke-dashoffset`），不使用旋转或闪烁。

## 4. 三种终态

| 终态 | 触发 | 行为 |
| --- | --- | --- |
| 返回 | `↑` / `Backspace` | 镜头退回封面；路径收回；不重放昂贵动画 |
| 减少动态 | 系统偏好或 `?reduced=1` | 直接切到封面或目录终态；目录仍有纵深；`←→` 仍可选章 |
| 渲染失败 | 渲染器抛错 | 保留静态封面与静态章节列表；键盘导航继续可用；错误信息可读 |

## 5. 两种渲染器的一致性

- 封面、目录、路径、投影和键盘状态完全共享，唯一差异是渲染器。
- 冻结帧显示两种渲染器在 p = 0 与 p = 1 的构图基本一致。
- DOM 版本的文字是真实 DOM，可选中、可被辅助技术读取；Three.js 版本为 CanvasTexture 平面。
- 一致性检查见 `test/opening/tools/verify.py`。
