05 / Scrollytelling material

A page that turns

Scroll the right side. The left stage stays in place and changes its visual state as the story moves forward.

Start with
an atmosphere.01 / opening frame
Then show
the system.02 / working state
Leave a trace.03 / final frame
01 / INTRODUCE

Let the first frame set the temperature.

Use a gradient, a quiet image or a single sentence to establish the world before asking the visitor to understand the system.

02 / EXPLAIN

Let interaction become the evidence.

A terminal that types, a command that switches, or a stage that responds to scroll can turn an abstract promise into something observable.

03 / REMEMBER

End on an image that stays with you.

The final frame does not need to explain everything. It needs to give the story a shape that can be carried into the next page.
