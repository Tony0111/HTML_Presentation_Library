# SYNAPSE FIELD - 脑机接口演示示例设计

> 文档状态：内容与版式设计稿 v0.1  
> 项目目录：`bci-synapse-demo/`  
> 基础模板：`../presentation-template/`  
> 演示性质：未来脑机接口概念示例；数字、指标和场景均为视觉占位，不构成医学或技术事实陈述。

## 1. 演示定位

这是一个用于展示“脑机接口如何把神经活动转化为可交互意图”的未来产品概念演示。它不解释完整神经科学，也不模拟真实临床设备；它用一条清楚、连续的叙事路径，让观众直观看到信号从采集、解码、反馈到个体适配的过程。

核心句：

> 从神经活动到可感知的意图。

演示沿用空间屏风模板的标题页、弧形目录、镜头穿越章节和反向返回逻辑。新的内容不改动原模板目录，所有文件都独立放在 `bci-synapse-demo/` 中。

## 2. 设计命题

脑机接口的画面常被处理成发光大脑、密集蓝色电路或医疗扫描图。本示例避开这些已被用滥的符号，转而把“信号正在被理解”作为视觉主题：

- 神经活动是稀疏、漂移、需要被提取的微弱光点与波形。
- 解码不是一个黑盒结果，而是空间中逐步收束的轨迹和概率场。
- 反馈不是一条箭头，而是一条回到身体感知的闭环光路。
- 个体适配不是表格堆砌，而是界面逐渐贴合某个人的节奏。

整体感觉应当是精确、安静、接近科学仪器，但带有可见的诗意和未来感。

## 3. 从素材库继承的视觉模式

`Design Asset Library` 中的模式只借鉴视觉关系和交互结构，示例使用自己的内容、代码与素材。

| 本地模式 | 在脑机接口演示中的转化 | 使用位置 |
| --- | --- | --- |
| 动态最后一个词 | 固定主句，只替换“意图 / 触觉 / 行动”等结果词；词槽宽度固定 | 标题页、结尾页 |
| 三角灯光场 | 由低亮度节点组成的“神经读出场”，自动沿连接边传播脉冲 | 标题页背景、第一章 |
| 深色线性渐变 | 从章节主题色向深黑场地平滑过渡，提供景深而不覆盖文字 | 每个章节页背景 |
| 单指标数据叙事图表 | 用一条“示意信号清晰度”曲线讲述校准过程，保留单位和“illustrative”标记 | 第四章 |
| 比较表与迷你趋势线 | 用三次虚构会话比较稳定度、延迟与舒适度，强调个体化的变化 | 第四章第二屏 |
| 稳定媒体舞台 + 文本步骤 | 在一个不动的神经视图中，随着章节内部步骤切换解码状态 | 第二章、第三章 |

## 4. 视觉系统

### 4.1 首版主题：Cortical Current

| 角色 | 色彩 | 用法 |
| --- | --- | --- |
| 舞台底色 | `#05080D` | 全局深黑空间与面板阴影 |
| 神经主光 | `#46E7FF` | 信号、当前焦点、文字细线 |
| 适配强调色 | `#C8FF65` | 已确认连接、稳定状态、章节小标签 |
| 反馈强调色 | `#FF7A6E` | 反馈回路、异常或待处理状态 |
| 深层蓝绿 | `#0A2732` | 玻璃内部、远端屏幕与渐变底层 |
| 文字 | `#EAF7FA` | 标题和关键信息 |

色彩不以紫色渐变作为主视觉。每页维持大面积深黑、少量冷青主光和一处状态强调色，保证远距离投影下的对比度。

### 4.2 材质与空间

- 目录面板继续采用半透明玻璃、金属细框和微弱内反射。
- 玻璃后面的视觉使用“神经信号图谱”，不使用真实 MRI、脑部照片或医疗机构素材。
- 当前面板有缓慢移动的折射光带；相邻面板只显示静态、低亮度关键帧。
- 背景节点自动发出低频脉冲，不随鼠标变化，符合键盘演示的使用方式。
- 每个章节拥有独立的光学形状，避免五张面板只是换颜色。

### 4.3 字体与文案层级

- 一级标题：英文短语，大写无衬线，控制在两行以内。
- 中文解释：一行短句，作为可选副标题，不承担主要视觉重量。
- 章节编号：衬线斜体数字，作为空间定位锚点。
- 数据与状态：等宽字体，小字号，只显示必要数值。
- 不在一页中同时出现大标题、长段解释、多个图表和表格；每一屏只有一个阅读焦点。

## 5. 信息结构

```text
标题页
  -> 一级目录：5 个空间屏风章节
      -> 01 LISTENING：采集微弱活动
      -> 02 DECODING：把模式转为意图
      -> 03 THE LOOP：让反馈回到感知
      -> 04 ADAPTING：为一个人持续校准
      -> 05 BEYOND THE SIGNAL：界面的新边界
          -> 结尾页：重新回到标题命题
```

原始概念稿把每个一级章节压缩为两屏，用于先验证视觉方向。本次扩写将每个一级章节视为一个独立的小型 PPT，统一拆成五页：章节开场、问题背景、过程变化、证据读出、观点收束。这样完整演示目标为 28 个核心状态：标题页、目录页、5 个章节 × 5 页、结尾页。代码可以分阶段实现，但页面顺序、文案和视觉职责以第 11 节的完整方案为准。

## 6. 页面逐屏设计

### 00. 标题页：SYNAPSE FIELD

**标题**

```text
SYNAPSE
FIELD
```

副句保持固定结构：`FROM NEURAL ACTIVITY TO [INTENT / TOUCH / ACTION]`。方括号中的词低频切换，词槽宽度固定，避免版面移动。

**背景与排版**

- 左侧保留大比例标题和演讲信息；右侧及深处是被景深模糊的目录屏风。
- 屏风背后加入低亮度三角神经读出场：12 至 16 个节点、少量连接线、每 5 至 8 秒一次的自动脉冲。
- 标题不是覆盖在卡片里，而是直接位于舞台空间上。
- 进入目录时，标题略微拉开、三角节点扩散，镜头推进到第三块目录面板。

### 01. 一级目录：THE SIGNAL PATH

目录仍为五块弧形环绕玻璃屏风，当前章节正对镜头，左右相邻章节只露出部分。

| 章节 | 标题 | 面板视觉 | 目录副句 |
| --- | --- | --- | --- |
| 01 | LISTENING | 青色电极网格与稀疏波形 | Find the signal inside the noise. |
| 02 | DECODING | 多条轨迹收束成一个亮点 | Make intention legible. |
| 03 | THE LOOP | 珊瑚色闭环光带穿过玻璃 | Return feedback to the body. |
| 04 | ADAPTING | 深蓝曲线逐步贴合一条参考线 | Learn one person at a time. |
| 05 | BEYOND THE SIGNAL | 远处节点向开放空间扩展 | Design the boundary with care. |

当前面板显示完整图形、编号和短副句；相邻面板保留编号和局部视觉，远端面板只保留轮廓和主题色。

### 02. 第一章首页：LISTENING / FIND THE SIGNAL

**叙事作用**：先让观众理解输入并不是清晰指令，而是需要筛选的微弱活动。

**空间视觉**：中央是一块半透明电极阵列，128 个低亮度点按微小偏移排列；少数点形成从左向右传播的青色信号。远处叠一层半透明噪声波形，当前信号经过时才清晰。

**排版**：

- 左下：`01`、标题和 16 至 20 个词的短句。
- 右上：一个细小状态标签，例如 `INPUT FIELD / ILLUSTRATIVE`。
- 不显示真实患者、真实脑电图或医疗诊断描述。

### 03. 第一章证据屏：THE READOUT

**版式**：左侧 70% 是缓慢行进的多通道波形，右侧 30% 是 3 个简短状态读数。

```text
SIGNAL WINDOW          480 ms
ACTIVE CHANNELS        128
READOUT STABILITY      0.82
```

这些数值明确标记为示意。波形在按下章节内部下一步时由嘈杂变得可读，视觉上对应“提取”而非“测量结论”。

### 04. 第二章首页：DECODING / MAKE INTENTION LEGIBLE

**叙事作用**：把“信号存在”推进到“系统理解了什么”。

**稳定媒体舞台**：左侧保持一个深色的三维轨迹场，数百个微小点从分散状态逐渐向三个标签区域收束：`MOVE`、`SELECT`、`REST`。右侧文字在章节内部的三个步骤中切换。

| 内部步骤 | 右侧短句 | 舞台变化 |
| --- | --- | --- |
| Pattern | A pattern emerges. | 点云仍分散，少量连线发光 |
| Intent | An intent gains weight. | 一个区域亮度和尺寸提升 |
| Choice | A choice becomes visible. | 当前区域形成清晰的焦点光环 |

此处采用素材库“稳定媒体舞台 + 文本步骤”的模式，但由键盘步骤驱动，不使用网页滚动。

### 05. 第二章证据屏：THE DECODER LENS

**版式**：中心为一个简洁概率扇形图，三种意图以不同透明度叠加；左侧是步骤编号，右侧是当前置信度条。

视觉重点是“概率正在收束”，不把它包装为准确率宣传。读数使用 `ILLUSTRATIVE CONFIDENCE` 标签。

### 06. 第三章首页：THE LOOP / FEEDBACK RETURNS

**叙事作用**：强调脑机接口不是单向读取，而是一个持续校正的闭环。

**空间视觉**：一条珊瑚色的细光带从左侧信号层进入中央解码器，再绕到右侧触觉回馈面。光带不是箭头，而是闭合的半透明环；经过当前节点时产生一次柔和的折射扩散。

**排版**：大标题放在右下，避免压住闭环；左下只放一条解释：`What the system gives back changes what it can read next.`

### 07. 第三章证据屏：A SENSE OF RETURN

**版式**：中央保留闭环图。环上的三个节点依次显示 `READ`、`INTERPRET`、`RETURN`，下方以三段短而等宽的状态线展示同一循环中的时间顺序。

进入时光带先走完一圈，再让三个节点亮起。画面避免模拟人体皮肤或医疗治疗过程。

### 08. 第四章首页：ADAPTING / LEARN ONE PERSON

**叙事作用**：从系统能力转向人的差异。

**空间视觉**：一条淡青参考曲线横跨面板；三条代表虚构会话的细线从不同位置开始，在右侧逐渐靠近参考曲线。背景为从青色向深黑消退的线性渐变。

**排版**：标题置于左上，曲线是主角。右下只有一个状态注释：`CALIBRATION / SESSION 03`。

### 09. 第四章证据屏：THE PERSONAL BASELINE

**版式**：左侧为一条单指标“示意信号清晰度”时间曲线；右侧为 3 行会话比较表，每行包含一个 sparkline。

| 会话 | 稳定度 | 延迟 | 舒适度 |
| --- | --- | --- | --- |
| 01 | 0.62 | 42 ms | 0.58 |
| 02 | 0.74 | 35 ms | 0.71 |
| 03 | 0.86 | 29 ms | 0.84 |

页脚必须标明 `ILLUSTRATIVE SESSION DATA / NOT CLINICAL MEASUREMENT`。这是素材库数据图表和比较表模式的应用边界。

### 10. 第五章首页：BEYOND THE SIGNAL / DESIGN THE BOUNDARY

**叙事作用**：结尾不做夸张承诺，而是把焦点放在交互边界和人的选择上。

**空间视觉**：当前玻璃面板的边框在远处逐渐分解为开放节点；节点没有汇成大脑轮廓，而是留出大量黑色空间。最亮的青色节点停在画面中央偏右。

**排版**：标题在左侧，短句为 `The interface should remain accountable to the person inside the loop.`

### 11. 第五章证据屏：THREE QUESTIONS

屏幕不使用大量文字，而是按顺序出现三个单词组：

```text
CONSENT
CONTROL
CONTEXT
```

每个词出现时，目录中对应的一个远端节点亮起。它们是设计问题的提示，不给出临床或社会结论。

### 12. 结尾页：THE SIGNAL IS ONLY THE BEGINNING

结尾回收标题页的句式：`FROM NEURAL ACTIVITY TO [CHOICE]`。词语停止切换，最终定格为 `CHOICE`。

镜头从第五章面板后退，重新看到所有屏风围成的弧线。标题在前景出现，三角神经读出场的节点逐渐熄灭，只留下一个稳定的青色节点。

## 7. 章节内页的通用排版规则

```text
┌─────────────────────────────────────────────────────────┐
│ 小型状态标签                                      页码   │
│                                                         │
│                 主视觉 / 数据舞台                       │
│                                                         │
│  章节编号 + 标题                         一句短解释      │
│  细微进度线                               数据来源注记    │
└─────────────────────────────────────────────────────────┘
```

- 主视觉至少占据画面 60% 的可用面积。
- 标题固定在左下或左上；同一章节的两屏只移动一个层级，保持阅读记忆。
- 数据页使用右侧窄栏或底部横条，不让图表变成密集仪表盘。
- 所有“示意”数据使用等宽小字和固定位置的说明，保证不会被误读为真实结论。
- 页面之间通过同一个相机和环境光连接，不显示传统的白底幻灯片翻页。

## 8. 动画节奏

| 场景 | 动画 | 时长建议 |
| --- | --- | --- |
| 标题 -> 目录 | 标题拉开、节点脉冲扩散、镜头推进、屏风解除模糊 | 1.5 秒 |
| 目录切换 | 弧形屏风整体旋转，新面板转正 | 0.85 秒 |
| 进入章节 | 镜头穿过当前玻璃面板，当前面板放大成入口 | 1.3 秒 |
| 章节内步骤 | 主视觉局部状态交接，文字短距离淡入 | 0.55 秒 |
| 返回目录 | 镜头沿原路径后退，当前面板回到弧线 | 1.3 秒 |
| 返回标题 | 屏风收拢、景深加深、标题恢复 | 1.15 秒 |

所有长时动画只由键盘动作触发。环境中的节点脉冲、折射光带和词语切换保持低频，确保它们是气氛，不会成为演讲内容的竞争者。

## 11. 章节内部 PPT 化方案（本次扩写）

### 11.1 章节不再是一张海报

每一个一级目录都是一段可以独立播放的小型演示文稿。进入目录中的某个章节后，观众应当经历一个完整的“提出问题、展示过程、给出读出、留下观点”的节奏，而不是只看到一张放大的章节封面。

每章固定五页，页面职责如下：

| 页码 | 页面角色 | 观众应该获得什么 | 视觉重点 |
| --- | --- | --- | --- |
| 01 | OPENING | 知道这一章要讨论什么 | 一句命题 + 主视觉建立 |
| 02 | CONTEXT | 理解问题从哪里来 | 输入、环境或参与者关系 |
| 03 | PROCESS | 看见系统如何变化 | 动态轨迹、闭环或曲线 |
| 04 | READOUT | 得到一组可读的示意结果 | 轻量数据、状态条或比较 |
| 05 | TAKEAWAY | 记住这一章的观点 | 结论短句 + 视觉收束 |

五页不是传统白底幻灯片的平移。页面始终处在同一座深色空间里，章节背景、面板材质和环境光保持连续；变化发生在中央舞台、文字层和信号状态上。这样观众会感觉自己正在穿过一套空间化 PPT，而不是离开一个页面再打开另一个页面。

### 11.2 每一页的固定骨架

每个章节页使用同一套信息骨架，避免不同章节之间失去阅读记忆：

```text
┌─────────────────────────────────────────────────────────┐
│ CHAPTER / STATE                         02 / 05         │
│                                                         │
│                  主视觉或数据舞台                       │
│                                                         │
│ ENGLISH TITLE                                          │
│ 中文解释：一到两句，说明当前画面正在发生什么。            │
│                                                         │
│ READOUT / ILLUSTRATIVE        中文页脚观点               │
└─────────────────────────────────────────────────────────┘
```

- `CHAPTER / STATE`、页码、`READOUT`、`ILLUSTRATIVE` 等属于装饰和系统标识，可以使用英文。
- 观众真正需要理解的解释、结论和数据含义使用中文。
- 英文主标题保持短、硬、有方向感；中文说明不超过两行，避免变成讲稿墙。
- 每页只设置一个主视觉焦点：波形、点云、闭环、曲线、节点场五者之一。
- 页码显示为 `01 / 05`，位于固定位置；章节内翻页时位置不移动。
- 数据页必须有 `示意数据 / 非临床测量` 或同义中文注记，不能只依赖英文小字。

### 11.3 第一章：LISTENING / 找到信号

**章节目的**：让观众先接受一个前提：脑机接口面对的不是一条干净指令，而是一片需要筛选、提取和确认的活动。

#### 01 / OPENING — `FIND THE SIGNAL`

- **屏幕中文**：`输入不是指令，而是一片需要被辨认的活动。`
- **辅助中文**：`先听见变化，再谈理解。`
- **主视觉**：半透明电极阵列占据画面中央，节点大多低亮度，少数青色节点形成一条很短的传播路径。
- **排版**：英文标题靠左下，章节编号 `01` 放在标题左侧；右上放 `INPUT FIELD / ILLUSTRATIVE`。
- **动画**：进入页面时阵列先处于噪声状态，约 0.8 秒后出现第一条可追踪的青色脉冲。
- **演讲重点**：不要把“信号”讲成已经完成的答案，而要讲成需要被辨认的起点。

#### 02 / CONTEXT — `THE READOUT`

- **屏幕中文**：`同一片活动里，只有少数变化会反复出现。`
- **辅助中文**：`系统先保留差异，再寻找稳定的节奏。`
- **主视觉**：左侧为 3 组不同密度的波形，右侧为简短通道标记；波形不模拟真实脑电图，只表现稀疏、漂移和重复。
- **数据标记**：`窗口 / 480 ms`、`活动通道 / 32`、`读出稳定度 / 0.82`，全部标记为示意。
- **排版**：画面左 70% 留给波形，右 30% 为纵向读数栏；读数栏不使用卡片堆叠，采用细线分隔。
- **动画**：按下一步后，杂乱波形的透明度下降，重复出现的波形逐渐变亮。
- **演讲重点**：这里展示的是“提取”的视觉关系，不是医学诊断或设备性能结论。

#### 03 / PROCESS — `NOISE TO RHYTHM`

- **屏幕中文**：`可读性不是把噪声删除，而是让节奏从噪声中站出来。`
- **辅助中文**：`被保留的不是最强的信号，而是最有关系的变化。`
- **主视觉**：一条青色主波形从左向右穿过半透明噪声带，经过当前焦点时留下短暂的光晕。
- **排版**：主波形横跨 80% 的舞台宽度；下方只保留一个小型状态词 `EXTRACTION`。
- **动画**：主波形按固定速度横向移动，经过三个节点时产生三次轻微折射；不使用过快的闪烁。
- **演讲重点**：把“读出”解释成持续的筛选关系，而不是按一下按钮就得到结果。

#### 04 / READOUT — `SIGNAL WINDOW`

- **屏幕中文**：`当一个变化能够被重复辨认，它才有机会进入下一步。`
- **辅助中文**：`这一页只展示示意读数，不代表真实测量。`
- **主视觉**：波形左侧保持运动，右侧出现一条逐渐收窄的信号清晰度曲线。
- **读数**：`清晰度 / 0.82`、`噪声底 / 下降`、`窗口 / 480 ms`。
- **排版**：大面积保持为空，曲线占画面 60%，读数集中在右下角，不做仪表盘化。
- **动画**：按下一步时清晰度曲线由低到高走完一次，随后停在稳定位置。
- **演讲重点**：强调“可继续处理”比“已经完全理解”更准确。

#### 05 / TAKEAWAY — `LISTENING IS ACTION`

- **屏幕中文**：`倾听不是等待答案，而是主动决定什么值得继续。`
- **辅助中文**：`下一章：让信号获得方向。`
- **主视觉**：电极阵列逐渐熄灭，只留下三枚稳定青色节点，节点之间出现一条通往右侧的细线。
- **排版**：标题置于左侧，中文结论位于标题下方；右侧留出通往下一个章节的空间。
- **动画**：最后一枚节点熄灭后，远处第二章面板的绿色轨迹亮起，为转入 `DECODING` 做准备。
- **演讲重点**：把第一章收束为“找到可用信号”，而不是“完成脑机接口”。

### 11.4 第二章：DECODING / 让意图可读

**章节目的**：展示系统如何从“存在信号”走向“形成可讨论的意图”，同时明确这是一种概率性的解释过程。

#### 01 / OPENING — `MAKE INTENT LEGIBLE`

- **屏幕中文**：`信号开始有方向，但方向还不是决定。`
- **辅助中文**：`解码的任务，是把可能性变成可以检查的路径。`
- **主视觉**：深色三维轨迹场中，数十个点从画面边缘向三个区域缓慢聚集。
- **装饰标签**：`MOVE / SELECT / REST`，三个标签保持距离，不提前宣布结果。
- **动画**：进入时点云分散，三个区域只有微弱的光晕；当前章节标题出现后，轨迹开始收束。
- **演讲重点**：强调解码是逐步变清楚的过程，而不是不可解释的黑盒。

#### 02 / CONTEXT — `PATTERN`

- **屏幕中文**：`第一步不是命名意图，而是确认某种形状正在重复。`
- **辅助中文**：`相似的变化被连接起来，形成一条可观察的轨迹。`
- **主视觉**：点云仍然分散，少数点之间出现低亮度连线；左侧显示小型步骤编号 `01`。
- **排版**：左侧是步骤和中文解释，中央 70% 为轨迹场，右侧保留三个未激活标签。
- **动画**：连线像低频电流一样逐段亮起，不能同时全部出现。
- **演讲重点**：让观众先看到“模式”，再看到“意图”。

#### 03 / PROCESS — `INTENT`

- **屏幕中文**：`当一组轨迹持续靠近同一个区域，意图开始获得重量。`
- **辅助中文**：`系统仍然保留其他可能性，只是当前方向更突出。`
- **主视觉**：`MOVE` 区域亮度和尺寸提升，`SELECT`、`REST` 保持可见但更透明。
- **读数**：`当前方向 / MOVE`、`示意置信度 / 0.68`。
- **排版**：当前区域在画面偏右位置形成焦点，文字位于左下，不遮挡轨迹。
- **动画**：当前区域出现柔和光环，光环扩散一次后稳定；不使用跳动式百分比动画。
- **演讲重点**：说明“更可能”不等于“确定”，界面应该把不确定性留下来。

#### 04 / READOUT — `CHOICE`

- **屏幕中文**：`当选择可见，人才有机会在动作发生前确认它。`
- **辅助中文**：`界面展示的是一个可被检查的候选结果。`
- **主视觉**：三个意图区变成清晰的三角布局，当前区域形成稳定焦点；底部显示一条简短置信度条。
- **读数**：`候选结果 / MOVE`、`示意置信度 / 86%`、`其他可能 / 保留`。
- **排版**：左侧是中文说明，右侧是三角概率场；底部只放一条细进度线。
- **动画**：置信度条只在进入本页时走一次，停留后不持续增长。
- **演讲重点**：把“可见的选择”作为人与系统共同确认的界面节点。

#### 05 / TAKEAWAY — `THE DECODER LENS`

- **屏幕中文**：`好的解码器不是替人决定，而是把可能的方向照亮。`
- **辅助中文**：`下一章：把结果送回感知，形成闭环。`
- **主视觉**：三个标签逐渐退到背景，只留下一个透明的选择框和一条返回左侧的细线。
- **动画**：选择框缩小成一点绿色光源，珊瑚色光路从右侧开始生成，连接到第三章。
- **演讲重点**：自然引出反馈：如果系统输出不会回到人的感知，解码仍然是单向的。

### 11.5 第三章：THE LOOP / 让反馈返回

**章节目的**：让观众理解脑机接口不是“读完就结束”，而是读取、解释、返回、再次读取的连续循环。

#### 01 / OPENING — `FEEDBACK RETURNS`

- **屏幕中文**：`系统给出的反馈，会改变下一次被读取的信号。`
- **辅助中文**：`接口不是单向管道，而是一条会回到起点的路径。`
- **主视觉**：珊瑚色半透明闭环横跨画面，环内保留足够黑色空间；三个节点分别代表读取、解释、返回。
- **动画**：光带先完成一整圈，随后当前节点亮起；光带不使用箭头形状。
- **演讲重点**：用空间上的“回到原点”解释闭环，不依赖医学器官或皮肤意象。

#### 02 / CONTEXT — `READ`

- **屏幕中文**：`闭环从倾听开始，系统先确认当前发生了什么。`
- **辅助中文**：`没有新的读出，就没有可靠的下一步。`
- **主视觉**：环左侧节点变亮，周围出现一次短促扩散；右侧节点保持暗色。
- **排版**：标题和说明置于右下，避免压住环；左下只放状态词 `READ`。
- **动画**：读出节点的扩散半径固定，避免模拟心跳或人体脉搏。
- **演讲重点**：把“读”作为闭环的第一步，而不是输入端的静态图标。

#### 03 / PROCESS — `INTERPRET`

- **屏幕中文**：`解释发生在环的中段，系统把刚刚读到的变化转换成反馈。`
- **辅助中文**：`这里展示的是一次状态转换，不是一个不可见的黑盒。`
- **主视觉**：环中央的解码节点变亮，珊瑚光带经过时产生柔和折射。
- **读数**：`转换延迟 / 42 ms`、`状态 / INTERPRET`，均标注为示意。
- **动画**：光带经过中心节点时只发生一次折射，之后恢复原来的亮度。
- **演讲重点**：强调系统内部需要被设计成可解释的过程。

#### 04 / READOUT — `RETURN`

- **屏幕中文**：`反馈返回之后，下一次读取已经处在不同的条件里。`
- **辅助中文**：`变化来自循环本身，而不是某一个孤立的瞬间。`
- **主视觉**：右侧返回节点亮起，闭环上出现三段等宽状态线：读取、解释、返回。
- **排版**：中央保留闭环，底部用横向时间线表达顺序；不使用复杂流程图。
- **动画**：三段状态线按顺序点亮，最后回到 `READ` 节点。
- **演讲重点**：把反馈解释为改变下一轮输入的条件。

#### 05 / TAKEAWAY — `A SENSE OF RETURN`

- **屏幕中文**：`真正的反馈，不是系统替人完成，而是让下一次协作更接近当下的人。`
- **辅助中文**：`下一章：同一套接口如何逐渐贴合不同的人。`
- **主视觉**：闭环缩小到画面中央，外圈熄灭，只留下三个相互连接的节点。
- **动画**：珊瑚色逐渐让位给青色和绿色，为第四章的适配曲线预留色彩。
- **演讲重点**：从“系统有能力”转向“系统是否能适应具体的人”。

### 11.6 第四章：ADAPTING / 为一个人持续校准

**章节目的**：把叙事从系统流程转向个体差异，展示模型如何在多次会话中逐渐贴近一个人，同时避免把示意指标包装成真实疗效。

#### 01 / OPENING — `LEARN ONE PERSON`

- **屏幕中文**：`同一套系统面对不同的人，不应该只给出同一个默认答案。`
- **辅助中文**：`适配从承认差异开始。`
- **主视觉**：一条淡青参考曲线横跨面板，三条虚构会话曲线从不同位置开始。
- **排版**：标题置于左上，曲线作为舞台主角，右下放 `CALIBRATION / ILLUSTRATIVE`。
- **动画**：三条曲线从不同起点同时出现，但速度略有区别，形成个体节奏差异。
- **演讲重点**：校准不是把人变成标准样本，而是让系统认识差异。

#### 02 / CONTEXT — `BASELINE`

- **屏幕中文**：`第一次会话建立的是参考，不是结论。`
- **辅助中文**：`模型先看到一个大致范围，再等待更多属于这个人的变化。`
- **主视觉**：参考曲线保持低亮度，第一条会话曲线偏离明显；左侧显示 `SESSION 01`。
- **读数**：`稳定度 / 0.62`、`延迟 / 42 ms`、`舒适度 / 0.58`，明确标注为虚构示意。
- **排版**：左 65% 为曲线，右 35% 为单列读数，不做多卡片仪表盘。
- **演讲重点**：第一次测到的差异应该被保留下来，而不是立即被平均掉。

#### 03 / PROCESS — `SESSION 02`

- **屏幕中文**：`第二次会话不是重复，而是一次更接近个人节奏的修正。`
- **辅助中文**：`曲线向参考线靠近，但仍保留属于这个人的偏移。`
- **主视觉**：第二条曲线亮度提升，逐渐靠近参考曲线；第一条曲线退到背景作为记忆。
- **读数**：`稳定度 / 0.74`、`延迟 / 35 ms`、`舒适度 / 0.71`。
- **动画**：曲线沿既定路径移动，靠近参考线时减速，不产生突然吸附效果。
- **演讲重点**：个体化不是让所有曲线重合，而是减少不必要的误解。

#### 04 / READOUT — `THE PERSONAL BASELINE`

- **屏幕中文**：`第三次会话显示的是趋近，而不是完美。`
- **辅助中文**：`所有指标都是展示叙事关系的示意值，不是临床测量。`
- **主视觉**：左侧显示三条曲线的收敛过程，右侧显示三行会话比较表；每行附一条极简 sparkline。
- **读数**：`会话 01 / 0.62`、`会话 02 / 0.74`、`会话 03 / 0.86`。
- **排版**：比较表固定在右侧 30% 宽度，表头和注记使用等宽字体；不让表格占据整个屏幕。
- **动画**：表格行按会话顺序出现，第三行出现后曲线在右侧形成稳定交汇。
- **演讲重点**：让观众看到“变化的趋势”，而不是被某一个大数字带走。

#### 05 / TAKEAWAY — `ADAPTATION IS MEMORY`

- **屏幕中文**：`适配的价值，不是抹平差异，而是记住哪些差异值得被尊重。`
- **辅助中文**：`下一章：当接口越来越强，边界应该放在哪里？`
- **主视觉**：三条曲线淡出，只留下贴近参考线但不完全重合的一条曲线。
- **动画**：曲线在右侧稳定后，背景节点向第五章开放空间扩散。
- **演讲重点**：从性能叙事过渡到边界和责任叙事。

### 11.7 第五章：BEYOND THE SIGNAL / 设计边界

**章节目的**：结尾不夸大未来能力，而是把注意力放回到同意、控制、语境和人的主动性。

#### 01 / OPENING — `DESIGN THE BOUNDARY`

- **屏幕中文**：`接口越接近人的意图，边界就越需要被看见。`
- **辅助中文**：`能力之外，还要设计谁可以决定、谁可以暂停。`
- **主视觉**：节点网络从面板边框向外扩散，中央留出大面积空白，不形成大脑轮廓。
- **排版**：标题位于左侧，中央空白作为视觉主角；右上使用 `OPEN FIELD / ILLUSTRATIVE`。
- **动画**：节点扩散到边界后减速，中央始终保留可呼吸的黑色空间。
- **演讲重点**：明确最后一章讨论的是设计命题，不是产品承诺。

#### 02 / CONTEXT — `CONSENT`

- **屏幕中文**：`任何读取和反馈，都应该建立在清楚、可撤回的同意上。`
- **辅助中文**：`同意不是一次性按钮，而是贯穿整个互动过程的状态。`
- **主视觉**：左侧节点向中央靠近，但在到达中心前停下；中心保持未占用。
- **排版**：英文关键词 `CONSENT` 位于左上，中文解释位于画面下方；不使用警示红色大面积铺陈。
- **动画**：靠近中心的节点出现一次停顿，随后返回原位，表达可撤回。
- **演讲重点**：把同意设计成持续存在的交互状态。

#### 03 / PROCESS — `CONTROL`

- **屏幕中文**：`系统可以提供建议，但暂停、确认和拒绝必须清晰可见。`
- **辅助中文**：`控制权不应被藏在复杂设置里。`
- **主视觉**：节点网络出现一条清晰的可中断路径，路径上有三个状态点：继续、暂停、返回。
- **排版**：三种状态横向排列，当前状态用绿色细线标记，不使用大按钮卡片。
- **动画**：路径到达暂停点时完整停住，再由下一步继续向前。
- **演讲重点**：把控制权落到具体的界面动作上，而不是抽象口号。

#### 04 / READOUT — `CONTEXT`

- **屏幕中文**：`同一个信号离开语境之后，可能会被解释成完全不同的事情。`
- **辅助中文**：`系统需要知道自己不知道什么。`
- **主视觉**：同一组节点在两个不同的光场中呈现两种透明度，显示解释依赖上下文。
- **排版**：左右两侧为 `CONTEXT A` 和 `CONTEXT B`，中间保留一条不确定性分隔线；中文解释置于底部。
- **动画**：左右场景交替增强，但不会给出一个被宣称为“正确”的唯一答案。
- **演讲重点**：强调能力边界和语境依赖，避免把意图识别说成万能翻译器。

#### 05 / TAKEAWAY — `LEAVE IT OPEN`

- **屏幕中文**：`最好的未来界面，不是替人完成一切，而是让人始终能够参与决定。`
- **辅助中文**：`FROM NEURAL ACTIVITY TO CHOICE`
- **主视觉**：所有网络节点退到远处，只留下一个稳定青色节点和开放的黑色场。
- **排版**：英文标题居中偏左，中文结论位于下方；画面不再放数据表或复杂图形。
- **动画**：稳定节点保持亮起，镜头后退，重新看到五块屏风的弧线，为结尾页做准备。
- **演讲重点**：用一个开放问题结束，而不是用“技术已经解决问题”的结论结束。

| 当前状态 | 按键 | 行为 |
| --- | --- | --- |
| 目录 | `Enter` / `Space` / `ArrowDown` | 进入当前章节第 01 页 |
| 章节第 01 至 04 页 | `ArrowRight` / `ArrowDown` / `Enter` / `Space` | 播放到下一页 |
| 章节第 02 至 05 页 | `ArrowLeft` | 返回上一页 |
| 章节第 05 页 | 无操作 | 停留片刻后自动返回目录 |
| 章节第 05 页 | `ArrowRight` / `Enter` / `Space` | 立即触发返回目录动画 |
| 任意章节页 | `ArrowUp` / `Backspace` | 立即返回目录，保留反向镜头动画 |
| 目录 | `ArrowUp` / `Backspace` | 返回标题页 |
| 任意状态 | `F` | 进入或退出浏览器全屏 |
| 任意状态 | `Escape` | 只退出浏览器全屏，不改变演示层级 |

最后一页自动返回的停留时间建议为 3 至 4 秒，足够读完中文结论，又不会让演示停在章节末尾。只要用户提前按下一步，返回应立即发生。返回目录后，当前章节仍保持选中，方便继续向左或向右选择其他章节。

### 11.9 配置文件中的章节页模型

为了让每个章节真正具备 PPT 内容，`data/presentation.config.js` 中的章节对象应包含 `pages` 数组。每个页面至少包含以下字段：

```js
{
  label: "02 / THE READOUT",
  title: "EXTRACT THE RHYTHM",
  body: "把当前页面需要观众理解的中文内容放在这里。",
  readout: "CHANNELS / 32",
  metric: "READOUT STABILITY 0.82",
  note: "示意数据 / 非临床测量",
  visual: "signal-window"
}
```

- `label` 和 `title` 使用英文，作为章节识别和视觉装饰。
- `body`、`note` 使用中文，负责解释和收束观点。
- `readout`、`metric` 可以使用英文缩写和单位，但必须配合中文语义或示意注记。
- `visual` 决定页面使用波形、点云、闭环、曲线或开放节点场。
- 页面内容不直接写死在 `app.js` 中；修改演示主题时只改配置和对应视觉函数。

### 11.10 中文文案与英文装饰的边界

页面中出现的英文不是为了替代中文解释，而是用来建立系统感、章节编号和视觉节奏。具体规则如下：

1. 英文负责标题、章节名、状态名、页码和短标签，例如 `FIND THE SIGNAL`、`READOUT`、`SESSION 03`。
2. 中文负责叙事、因果关系、数据解释、设计观点和演讲提示。
3. 不使用整段英文说明来制造“科技感”，避免观众只能看到装饰却不知道页面在讲什么。
4. 数据的单位可以保留英文格式，例如 `42 ms`、`0.82`，但旁边必须有中文解释或 `示意` 标记。
5. 每页最多出现一个英文主标题、两个英文状态标签和一组页码信息，其余信息优先使用中文。
