# Vercel 三角灯光场

## 来源观察

- 参考页面：[Agentic Infrastructure - Vercel](../../sources/vercel-agentic-infrastructure/Agentic%20Infrastructure%20-%20Vercel.html)
- 原页面的首页背景是 WebGL2 Canvas 着色器，不是静态 SVG 或普通 CSS 三角形。
- 三角形内部有 10 个发光节点，鼠标移动时通过 pointer 坐标寻找最近节点，节点权重沿三角形边缘扩散。

## 视觉结构

1. 三角形是暗色背景中的几何骨架，边缘分别使用红、绿、蓝三种光色。
2. 节点平时保持很低的环境亮度，因此画面不会一直抢夺标题注意力。
3. 鼠标靠近时，最近节点变亮，周围节点同步获得较弱的光晕，形成“光正在传播”的感觉。
4. 轻微的呼吸动画和噪声让灯光不像一个完全静止的 CSS 点。

## 本地复刻方式

`DESIGN-ASSET-LIBRARY.html` 中的复刻使用 Canvas 2D：

- 10 个节点按 1、2、3、4 行排列。
- 使用 pointermove 计算鼠标与每个节点的距离。
- 使用指数衰减把距离转换成发光能量。
- 使用径向渐变绘制光晕，使用三条彩色边绘制结构。
- 提供暂停按钮和 `prefers-reduced-motion` 处理。

Canvas 2D 版本更适合作为个人素材库中的可复制片段；正式项目如果需要更高密度的粒子、HDR 光照、噪声扭曲或更复杂的阴影，可以把同样的状态模型迁移到 WebGL2 shader。

## 适合使用

- 首页的黑色英雄区背景
- AI、基础设施、开发者工具和硬件主题
- 需要让静态几何图形对鼠标产生反馈的页面
- 不希望加载大型图片，但仍然需要一个有生命力的第一屏

## 使用边界

- 保持节点数量和动画幅度克制，否则背景会变成主角。
- 触屏设备没有持续 hover，应允许它退化为低亮度静态状态。
- 交互效果必须有静态首帧，避免 Canvas 加载失败后留下空白区域。
- 如果复用原站的字体、shader、贴图或代码，需要另外确认授权；素材库只记录交互结构和本地独立复刻。
