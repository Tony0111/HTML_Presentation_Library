# Hover Card Row

页面下方并排的章节卡片：悬停时卡片抬起、产生 3D 倾斜并展开更多信息，其余卡片自动退到背景。适合 PPT 的分章页、议程页或产品卖点页。

灵感来自 `github_res/movie_card_hover`（纯 HTML/CSS 的卡片悬停效果），这里扩展成一行 3～4 张、带 3D 立体的版本。

## 使用

双击 `index.html` 即可，不需要 Node.js、npm、服务器或网络。

- 鼠标悬停卡片：抬起 + 立体倾斜 + 展开说明
- 左上角按钮：在 3 张 / 4 张布局之间切换
- 触屏设备：直接显示完整信息

## 说明

- 卡片画面是用 CSS 渐变生成的，不依赖任何外部图片，因此完全离线且没有素材授权问题。
- 3D 倾斜使用少量 JavaScript 跟随指针；其余视觉效果（抬起、展开、相邻卡片变暗）都是纯 CSS。
- 替换成自己的内容时，改 `.card` 里的标题、`--accent` / `--accent2` 颜色和说明文字即可。
