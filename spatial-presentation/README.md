# Spatial Presentation

面向组会进展与学科学习汇报的本地 HTML 演示模板项目，复用到约 10–20 分钟、20–30 页的演示。已确认采用深底封面 / 章节、浅底正文的艺术杂志编辑风，保留超大字与字体搭配、镜头推进的空间感；通过有限模块组合与 AI 辅助内容制作降低使用门槛。

**当前代码仍是玻璃屏风导航原型**，包含封面、目录与章节占位页；上述完整模板尚未实现。本次仅更新需求，不改变运行代码。整个文件夹可复制到另一台电脑，使用 Chrome 或 Edge 直接打开 `index.html`。

- [TECHNICAL-ARCHITECTURE.md](TECHNICAL-ARCHITECTURE.md)：旧空间原型技术方案，尚待按新需求更新，不代表完整模板已可用。

## 运行

双击 `index.html`。

建议在 `1920 x 1080` 或常见 `16:10` 桌面屏幕中使用，并在演示前按 `F` 进入浏览器原生全屏。

## 键盘控制（当前原型）

| 按键 | 操作 |
| --- | --- |
| `Enter` / `Space` | 从封面进入目录；从目录进入当前章节 |
| `ArrowLeft` / `ArrowRight` | 切换章节 |
| `Home` / `End` | 跳转第一章 / 最后一章 |
| `1` 至 `8` | 跳转对应编号章节 |
| `F` | 进入或退出浏览器全屏 |
| `ArrowUp` / `Backspace` | 返回上一级并播放反向过场 |
| `Escape` | 只退出浏览器全屏；窗口模式下不改变页面层级 |

## 内容维护（当前原型与目标）

当前配置位于 [data/presentation.config.js](data/presentation.config.js)，包含章节名称、简介、海报配色、主题与屏风布局参数。封面可见文字仍有部分直接写在 `index.html`，不能只修改配置就更新整套演示。5 张抽象海报由 Canvas 在浏览器内生成，不依赖外部图片。

可以将内容和修改意见交给 AI，由 AI 维护相关文件；目标工作流是“自然语言需求 → 可审阅的 Markdown 内容稿 → AI 更新运行配置 → 预览与修订”。审阅稿、模板指南与正文页型系统目前尚未实现，具体契约见需求文档。

核心场景、玻璃材质和动画实现位于 [js/app.js](js/app.js)。本轮未修改这些运行文件。
