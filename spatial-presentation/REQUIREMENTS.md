# Spatial Presentation — 学术汇报演示模板需求文档

> 文档状态：需求稿 v0.5；组会 / 学科学习场景、深浅混合风格、学术内容范围与封面保留方向已确认，具体样式待样稿确认。  
> 产品定位：学术内容 × 艺术杂志式表达 × 有限模块复用。  
> 交付载体：沿用本地 HTML 演示项目；本文中的“PPT”指演示文稿，不代表新增 `.pptx` 交付。  
> 技术参考：[TECHNICAL-ARCHITECTURE.md](TECHNICAL-ARCHITECTURE.md) 当前记录的是旧空间原型，尚未按本次需求重构。

**状态说明**：本文描述后续建设目标，不表示功能已经实现。“已确认”来自本轮使用需求；“建议默认值”用于推进设计，可以调整；“沿用约束”来自旧版需求。

## 1. 产品定位

制作一套可长期复用的个人演示模板，主要用于 **10–20 分钟、约 20–30 页的组会进展与具体学科的学习汇报**。模板不绑定某一学科，具体领域与材料在每次制作时提供。内容需要准确、清楚、有论证关系；表达上不采用刻板的学术幻灯片风格，而是借鉴艺术杂志的字体对比、编辑网格、留白、图文关系和视觉节奏。

核心不是每次重新设计，也不是制作一个无限自由的编辑器，而是：

> 从少量成熟的开场、目录、正文页型和视觉主题中选择组合，由 AI 填入内容并进行局部修改。

“Spatial”保留为空间感与运动连续性的设计能力，不再意味着每场汇报必须使用玻璃屏风。

### 2.1 本轮已确认

### 2.2 沿用的项目约束

- 交付为完整文件夹，资源随项目携带；复制到另一台电脑后直接打开 `index.html`。
- 面向桌面端 Chrome / Edge，支持本地 `file://` 运行；不要求安装开发工具、启动服务器或联网。
- 使用本地相对路径，不依赖 CDN、远程字体、远程素材或运行时 AI 服务。
- 以 `1920 × 1080`、`16:9` 全屏为设计基准，同时检查 `2560 × 1440` 和常见 `16:10` 显示环境。
- 键盘操作、全屏、减少动态效果模式、素材缺失提示继续保留。
- 暂不要求 PowerPoint 导入或导出。若必须提交 `.pptx` 或 PDF，应单独确认，不视为本轮已具备的能力。

### 2.3 可在样稿阶段补充，不阻塞需求定稿

- 首个样稿的具体学科、学习主题或一次组会材料尚未提供；不从项目名、相邻文件夹或占位内容推断真实研究方向。
- 具体字体、强调色、纸感与推进幅度用关键样页确认，不需要用户预先给出 CSS 参数。
- 图型、流程布局与数字编号引用为建议预设；有实际数据、复杂流程或课题组引用规范时再微调。
- 数学公式和算法专页本轮未列为必需，保留后续按材料增加的空间。

## 3. 产品目标、优先级与非目标

### 3.1 产品目标

1. 能够完整承载一场学术汇报，而非只有惊艳的封面与目录。
2. 封面、章节与关键结论具有记忆点，正文能持续阅读，重要数据看得清楚。
3. 通过有限模块和统一主题形成变化，不让 20–30 页成为互不相关的海报。
4. 同一个模板能更换研究主题、章节、图表和素材，多次复用而不改核心代码。
5. 用户只需要提供材料、审核内容和表达修改意见，AI 负责映射模板与维护配置。
6. 三类动效共同服务讲述节奏，不拖慢翻页，不迫使演讲者等待装饰动画。

发生冲突时，优先级为：**内容准确与可读性 → 演示稳定与讲述节奏 → 风格一致 → 装饰性效果**。

### 3.2 非目标

- 在线协作、账号、云存储、运行时调用 AI。
- 通用拖拽编辑器、任意布局画布、无限主题或大量近似页型。
- 每场汇报重新制作开场、重写动画或修改渲染引擎。
- 演讲者视角、双屏备注、私有计时器、遥控控制台。
- 自动播放整场演示、背景音乐和音效系统。
- 手机、触屏、鼠标专属交互，以及 VR。
- 把论文全文搬到幻灯片，或把每个正文页都制作成复杂三维场景。

## 4. 一场汇报的结构与节奏

### 4.1 两种叙事预设（建议）

两种场景共用主题、页型与导航，只调整内容组织，不开发两套独立模板。

```text
组会进展
封面 / 开场 → 目录
  → 本阶段目标与上次问题
  → 已完成工作、方法与过程
  → 结果 / 阶段证据、遇到的问题与讨论
  → 下一步计划、需要的反馈
  → 参考资料 → 结束 / Q&A

学科学习汇报
封面 / 开场 → 目录
  → 学习问题、范围与资料来源
  → 核心概念与知识关系
  → 方法流程、案例与比较
  → 自己的理解、尚未解决的问题与后续学习
  → 参考资料 → 结束 / Q&A
```

组会进展不必伪装成已有完整成果的论文报告；学习汇报应区分文献观点、自己的理解与待验证假设。这些是建议大纲，不将学科、阶段或章节名称写死。建议默认 3–6 章，目录继续兼容 3–8 章。章节扉页可选，不为凑页数强制插入。

### 4.2 翻页与节奏原则

- 正文按固定顺序连续翻页，跨章节时直接进入下一章，不强制反复回目录。
- 目录承担开场导览和临时跳转，不能成为每讲几页就必须操作一次的障碍。
- 默认一次前进按键推进一页；页内文字可以在入场时自动短序列出现，不额外消耗翻页按键。
- 首版默认不做“每按一次只出现一个要点”的逐条点击模式；若后续需要，另行确认。
- 封面、目录、章节扉页可以更有表现力；方法、表格和结果页应更稳定。
- 20–30 页是常用范围而非硬限制。页数包含封面、目录、扉页、资料页与结束页；动画步骤和临时打开目录不重复计页。
- 排练时核对整场时间；不按统一的“每页多少秒”机械分配。视频与转场耗时计入总时长。

### 4.3 首个完整样稿：建议 24 页

| 页型用途 | 建议数量 |
| --- | ---: |
| 封面 | 1 |
| 目录 | 1 |
| 章节扉页 | 3 |
| 大标题 + 要点 | 8 |
| 图文 / 研究图示 | 1 |
| 统计图（折线、柱状、散点各一页） | 3 |
| 流程图 | 1 |
| 数据表格 | 1 |
| 短视频 | 1 |
| 时间线 | 1 |
| 总结 | 1 |
| 参考资料 | 1 |
| 结束 / Q&A | 1 |
| **合计** | **24** |

样稿用于验证整场体验，主题由用户提供；文献短引同时出现在相关正文页，不只集中在末尾。这里的图型分配是模板覆盖测试建议，实际汇报只选适合材料的图，不为凑齐图型而编造数据。未提供真实研究材料时，必须明确标记为模板示例，不能伪造研究发现或引用。

## 5. 有限模块组合与定制边界

### 5.1 模板组合模型

```text
一场演示 = 一套全局视觉主题
         + 一种开场组合
         + 一种目录形式
         + 按内容排列的固定页型
         + 一套统一动效预设
```

同一场演示只采用一种主要开场和一种主要目录，不逐页更换风格。“组合”指选择已验证模块，不是任意拼装不兼容的布局与特效。

### 5.2 建议的初始规模

以下数量与名称是设计建议，不是用户已批准的成品清单：

| 模块 | 初始目标 | 说明 |
| --- | --- | --- |
| 视觉主题 | 1 套主主题 | `editorial-art`：深底封面 / 章节 + 浅底正文，采用同一字体和色彩体系 |
| 开场组合 | 2 种 | 首先实现 `spatial-push`：大字排版与镜头推进；之后补充 `type-reveal`：较轻的排版揭示 |
| 目录形式 | 2 种 | `editorial-index`：编辑式章节索引；`spatial-screens`：现有屏风方向的适配版 |
| 正文页型 | 8 种 | 要点、图文、统计图、流程图、表格、视频、时间线、结论 |
| 结构页型 | 5 种 | 封面、目录、章节扉页、参考资料、结束页 |
| 动效预设 | 1 套标准 + 减少动态模式 | 不给每页配置任意复杂时间轴 |

先完成“编辑风主题 + 大字空间推进开场 + 编辑式目录”的完整组合，再完成第二开场和第二目录的适配。统计图使用一个页型下的有限图型，文献短引是跨页共用能力，不为每种变化新增页型。保留旧原型不等于它已经接入新模板。

### 5.3 小改动范围

**日常允许**：替换文字、图片、视频、统计数据和文献条目；在既有预设内调整流程节点与连线；增删或重排页面；选择现有页型；更换主题配色与获准的字体组合；调整标题断行、图片裁切、强调词；在有限档位中调整动效强度。

**需作为模板开发处理**：新增页型、改变网格系统、自由拖动所有元素、新增任意镜头路径、改写核心交互、制作新的主题语言。

每个模块需要稳定 ID、缩略示例、适用内容、可调字段、容量建议和兼容说明。AI 不得因一页文字过多就临时创造一个无法复用的新页型。

## 6. 首个视觉方向：艺术杂志编辑风

### 6.1 整体气质

关键词：**编辑感、艺术性、研究叙事、字体对比、留白、克制的戏剧性**。

- 借鉴杂志的标题、导语、栏线、章节编号、图注和版面节奏，而不是仿造一本实体杂志的所有装饰。
- 不默认采用企业蓝白模板、满屏卡片、统一圆角面板或过度科幻的发光玻璃。
- 已确认继承当前封面的两项核心表达：**超大字与字体搭配、镜头推进的空间感**。样稿验证具体字形、比例、断行和推进幅度，不再把是否保留这两项作为待确认问题。
- 空间感可来自图层、裁切、景别变化和轻微视差，不要求所有页面采用三维材质。

### 6.2 字体与中英混排

- 建议使用有编辑感的衬线展示字体搭配清晰的无衬线正文；中文与英文均需有明确字体角色。
- 正文以中文叙述和英文术语自然混用；中文标题配短英文眉题是可选形式，不强制双语镜像。
- 英文斜体、超大编号、字重对比可以成为视觉语言，但不对中文正文使用夸张字距、描边或难辨认字体。
- 标题允许人工指定换行；长英文术语、数字、单位、上下标不能被错误裁切或断开。
- 具体字体待选型；随项目携带必要的字体文件与许可说明，并提供可读的回退字体。不能只依赖作者电脑已安装的字体。

### 6.3 色彩与背景

已确认采用 **C 方案：深底封面 / 章节页 + 浅底正文**。深浅角色固定在同一主题内，不随机逐页切换；具体色值、强调色与纸感强度仍由样稿确认：

- 浅底正文：暖白或浅灰背景、深色文字，保证图表和投影可读。
- 深底强调页：用于封面、章节扉页和关键结论，形成节奏。
- 一种主要强调色配少量辅助色；章节颜色共享同一色彩体系。
- 示例色彩方向可以是纸白、墨黑与砖红，也可以替换为其他完整主题，不把示例色值写死到内容中。
- 纸纹、颗粒、渐变与慢速光影只作轻背景，不盖住研究图、表格和正文。

### 6.4 网格、字号与容量

- 使用统一边距和编辑网格，允许固定的非对称构图；艺术性来自有控制的变化，不是随机摆放。
- 在 `1920 × 1080` 设计画布上，建议正文约 30–40 px，图注与来源约 20–24 px，标题按页型约 64–112 px；封面可更大。最终以中英实际内容和投影试读为准。
- 大标题通常不超过两行；要点页建议 3–5 条，每条 1–2 行。超量时优先精炼或拆页，不自动缩成小字。
- 表格初始建议不超过 6–8 个数据行、约 5 列；更多内容应拆分、聚焦或改用合适表达。
- 页面始终能识别主标题、核心内容、辅助说明；编号和装饰不能压过论点。

## 7. 页型需求

以下 ID 是未来模板契约的建议值，当前配置和代码尚不支持这些页型。

| 页型 ID | 内容与用途 | 设计及行为要求 |
| --- | --- | --- |
| `cover` | 题目、可选副标题、汇报人、单位、日期 | 长中文题目可读；支持选定开场；保留艺术性但不喧宾夺主 |
| `contents` | 章节编号、标题、可选短说明 | 支持两种目录形式；清楚显示当前章节与进入方式 |
| `section-divider` | 章节号、标题、可选一句引导 | 作为节奏变化；非每章强制；无实际内容时不重复堆页 |
| `headline-points` | 大标题 + 3–5 个短要点 | 最常用正文；重点词可强调；入场后内容稳定 |
| `split-media` | 标题、图片 / 本地 SVG / 研究图示、短说明、图注 | 固定图文分栏或主图布局；保留图的比例、图例和标注 |
| `chart-focus` | 标题、统计数据、坐标与单位、图例、结论、来源 | 首版支持统计图；建议内置折线 / 柱状 / 散点三种预设，用数据生成而非仅贴截图 |
| `process-flow` | 标题、步骤 / 概念节点、关系连线、短说明、来源 | 首版支持流程图；固定少量布局，节点与连线可配置，不做通用绘图编辑器 |
| `table-focus` | 标题、数据表、结论、单位与来源 | 使用可编辑的真实表格；表头、精度和对齐统一；高亮服务比较 |
| `video-focus` | 标题、本地短视频、封面图、说明 | 独立播放按键；不与翻页冲突；无视频时仍有可读说明 |
| `timeline` | 标题、3–6 个节点、时间 / 阶段标签、短说明 | 节点连接可逐步展开；全部节点最终稳定可读；区分真实时间与概念阶段 |
| `statement` | 核心发现、结论或下一步；可选少量支撑信息 | 用字号和留白强调观点，不能只有口号、缺失论证关联 |
| `references` | 文献 / 数据 / 媒体来源 | 首版必需；与正文短引共享来源记录；可拆页，统一格式，条目可定位 |
| `closing` | 简短总结、Q&A、可选联系方式 | 末页保持停留；不自动循环或退出 |

### 7.1 学术内容的最低要求

- 图、表、视频与引用支持标题、图注、单位和来源字段；不是每页都必须显示所有字段。
- 数据、结论、引用和示例内容有清晰边界。AI 不得为了填满版面编造数据、文献或研究结论。
- 表格允许重点行 / 列 / 单元格强调，但不以三维倾斜、动态扭曲等效果影响数值判断。
- 概念阶段的时间线不暗示真实时间比例；若按时间比例排布，必须有实际日期依据。
- 统计图、流程图和文献引用已确认为首版范围，不能仅用“可放图片”替代这些能力；已有论文图仍可放入图文页并注明出处。
- 公式排版与算法专页本轮未确认为必需，不阻塞首版，也不据此认定用户永远不需要；有实际材料后再扩展。

### 7.2 视频默认行为（建议）

- 视频为本地文件，建议以短片段为主；播放时长计入整场节奏。
- 进入视频页先显示封面，不自动播放或发声；`P` 播放 / 暂停，`M` 切换静音。
- 翻页键始终用于翻页；离开视频页立即暂停，不能在其他页继续出声。
- 重新进入该页默认回到封面和起点；视频结束停留在本页，不自动推进。
- 文件缺失、无法解码或播放失败时显示封面 / 替代说明与错误信息，仍可继续翻页。
- 用户可配置默认静音；若需要视频音轨，在演示前单独检查目标设备。

### 7.3 统计图（首版必需，具体预设为建议）

- 建议先支持折线图、柱状图和散点图，用于趋势、类别比较和变量关系；不扩展成任意图表编辑器。
- 图表由结构化数据生成。AI 可修改图型、系列、数据点、轴标题、单位、图例和强调项，用户不需要编辑绘图代码。
- 轴范围、数值、单位和系列对应关系必须能核对；缺失值不得自动当成零。柱状图的数值轴从零开始，其他图若采用截断或对数轴应明确标注。
- 有置信区间、误差范围或样本量时，只能使用材料中实际给出的值；首版可先用注释说明，不擅自推导统计量。
- 使用主题色、线型和标记共同区分系列；最终状态无需悬停即可看清重要信息，不依赖鼠标 tooltip 才能理解图表。
- 图表入场可使用短暂揭示，但不得通过三维透视、面积装饰或持续变形影响数值判断；图表阅读期间背景保持静态。

### 7.4 流程图（首版必需，布局为建议）

- 支持方法步骤、学习概念关系及工作流程；建议从横向步骤与简单分支两种布局开始，不提供任意拓扑的自动排版承诺。
- 节点具有稳定 ID、标签与可选短说明；连线引用节点 ID，必要时具有关系 / 条件标签。AI 修改内容和关系，不要求用户手写坐标或 SVG。
- 首版单页建议 3–7 个节点；超出固定布局容量时拆页或改用已有研究图示，不缩成密集小字。
- 节点文字和连线由可配置结构渲染，不把新建流程图保存为唯一来源的位图；旧文献原图可以作为带来源的图片保留。
- 方向、分支条件和汇合关系清楚，无穿字或遮挡；节点强调可配合自动入场序列，不改变一次按键翻一页的默认行为。

### 7.5 文献引用（首版必需，格式为建议）

- 同时提供正文短引 / 图注来源与末尾参考资料列表；不能只有末页书目而无法判断某个观点或图表来自哪里。
- 建议默认采用数字编号短引，例如 `[1]`；引文关联稳定来源 ID，按首次引用顺序生成显示编号。重排或删改页面后自动保持编号与条目一致。
- 文献来源记录至少包括稳定 ID、作者或机构、标题、年份；期刊 / 会议、DOI、URL、页码等按实际材料补充，不凭空填写。
- 同一文献多次使用复用一条记录；区分原图、改绘、引用观点和本人的分析。参考页可拆分，来源字不能为了塞满而无限缩小。
- DOI / URL 可作为可读文字随项目保存，但演示不自动请求外网；无需点击链接也能识别来源。需要展示的图和媒体仍应存放在本地。
- 草稿中缺失的引用标记为待补；只有明确标注的占位示例，不制作看似真实的虚构文献。

## 8. 三类动效与运动节奏

### 8.1 转场镜头

- 重点用于封面到目录、目录到章节、章节边界和少数关键结论。
- 首个开场必须体现已确认的镜头推进空间感：以超大标题为前景，目录或章节结构作为纵深目标，形成连贯的前后景关系；不能仅用普通淡入淡出代替。
- 镜头推进不强制依赖玻璃屏风，需先与编辑式目录配合；普通正文仍使用短距离版面推移、裁切揭示或淡入。
- 屏风穿越只用于可选空间目录；正文不逐页重复长距离运动，减少动态模式例外采用静态或短淡入。
- 返回路径应可理解；不要求每次返回都完整重播昂贵的开场。

### 8.2 文字动效

- 主标题可按行、词组或语义块揭示；中英混排不能因为逐字符拆分破坏排版。
- 正文以轻位移、透明度变化和短序列出现为主；默认入场后全部稳定显示。
- 不在阅读期间循环抖动、打字、变形或重新隐藏关键内容。

### 8.3 动态背景

- 封面、目录和章节页允许低频纹理、轻视差、柔和渐变或光影移动。
- 正文默认显著减弱；统计图、表格与流程图页使用静态背景，研究图与视频页也优先静态。
- 同一页只保留一个主要运动焦点，避免镜头、文字和背景同时争夺注意力。

### 8.4 建议时长与输入处理

| 动作 | 建议默认时长 |
| --- | --- |
| 开场 | 1.0–1.6 秒 |
| 章节级转场 | 0.5–0.8 秒 |
| 普通正文翻页 | 0.25–0.45 秒 |
| 文字入场 | 0.2–0.5 秒，与页面转场重叠 |
| 减少动态模式 | 0.15–0.25 秒淡入或直接切换 |

- 时长是样稿基线，不是用户已确认参数。总时长不能因连续串行动画叠加而显著增加。
- 动画中快速按键至多保留一次待处理导航；长按不连续跳过多页。
- 减少动态模式关闭空间推进、视差和装饰性背景运动，保留全部信息和操作；用户主动播放的内容视频不视为装饰动画。
- 页面在后台时暂停视频和非必要动画，返回后保持当前页，不自动开始播放视频。
- 不使用高频闪烁和眩晕式旋转；不把研究数据的更新与装饰动画绑定。

## 9. 键盘导航与全屏（建议契约）

本节是目标交互，不是当前 `js/app.js` 的快捷键说明；现有代码仍是旧原型行为。

| 场景 | 按键 | 目标行为 |
| --- | --- | --- |
| 封面 | `Enter` / `Space` / `ArrowRight` / `ArrowDown` | 播放开场并进入目录；初始选中第一章 |
| 目录 | `ArrowLeft` / `ArrowRight` | 选择上一章 / 下一章，不循环 |
| 目录 | `Home` / `End` / `1`–`8` | 选择首章 / 末章 / 对应章节；不存在则不响应 |
| 目录 | `Enter` / `Space` | 首次进入所选章第一页；从正文打开目录且仍选原章时回到原页；改选其他章则进入其第一页 |
| 目录 | `ArrowUp` / `Backspace` | 取消目录：从正文打开则回原页，从封面进入则回封面 |
| 正文及结束页 | `ArrowRight` / `ArrowDown` / `Space` / `PageDown` | 下一页；末页保持停留 |
| 正文及结束页 | `ArrowLeft` / `PageUp` | 上一页；到达开场目录时按目录规则处理 |
| 正文及结束页 | `ArrowUp` / `Backspace` | 打开目录并选中当前章，保存返回页 |
| 正文及结束页 | `Home` / `End` | 跳到第一张正文 / 结束页；不改变目录里的章节快捷键含义 |
| 视频页 | `P` / `M` | 播放暂停 / 静音切换，不触发翻页 |
| 任意页面 | `F` | 进入或退出浏览器原生全屏；不改变当前页 |
| 任意页面 | `Escape` | 仅退出浏览器全屏；不返回目录、不退出演示 |

补充规则：

- 第一张正文指目录之后的第一张页面，可以是章节扉页。参考资料与结束页归入最后一章的导航上下文。
- 目录作为临时导航打开时保留原页和选中章；全局页码不因临时导航重复计数。
- 本页提供可隐藏的简洁操作提示；视频页播放状态始终清楚。无需演讲者专属视图。
- 拦截翻页键的浏览器滚动行为，避免 `Backspace` 误退页面；避免同时触发媒体控件和页面导航。
- 全屏切换和窗口尺寸变化不重置页码、目录状态或媒体位置；浏览器拒绝全屏请求时保持可用并给出提示。
- 保留 `F11` 浏览器全屏使用方式。`F` 控制页面请求的原生全屏，不将两种模式当成同一个状态。

## 10. Design 艺术仓库的关系

上级 `Design/` 长期积累配色、字体、版式、动效与素材，本模板只消费整理后的设计资产，运行时不依赖整个仓库。每项资产记录稳定 ID、预览、来源、使用边界与可调参数；仓库中的参考不自动等于可直接使用或可再分发的素材。演示使用的资产必须复制到 `spatial-presentation/` 内并以相对路径引用，不依赖 `../assets/`、个人绝对路径或在线仓库。

## 11. 展示质量、运行与异常要求

### 11.1 显示与可读性

- 以 `16:9` 为内容画布；其他比例建议等比适配并使用主题背景补边，不拉伸图片或裁切核心信息。
- 目标桌面尺寸下不出现页面滚动条、文字溢出、图表裁切或页脚遮挡；小于 `1024px` 宽度不作为主要支持范围。
- 正文、图表和控件保持足够的对比度，不能只靠颜色区分重点或状态。
- 章节与页面使用可识别的语义结构；键盘操作和减少动态模式不丢失内容。
- 投影环境下检查细字、淡色、纹理、表格线和图注，而不只看笔记本近距离预览。

### 11.2 离线与资源

- HTML、CSS、JS、字体、媒体、第三方库和配置均随文件夹携带，不产生远程资源请求。
- 不引入必须启动服务、安装依赖或构建后才能演示的使用步骤。
- 核心内容采用可配置、可编辑的文字和结构，不能把整页烘焙成一张无法修订的截图。
- 具体模块可使用 Three.js，但默认编辑风正文不应被旧玻璃舞台强制绑定。
- 若可选 WebGL 效果不可用，至少保留可读封面、静态目录和正文导航；这是错误兜底，不是自动画质分档。

### 11.3 性能与异常

- 动画以目标设备上流畅、稳定为前提，目标为 60 FPS；用真实演示设备检查，不以增加特效数量作为验收。
- 不同时播放多页媒体或在隐藏页运行重背景动画；不因反复翻页持续累积资源。
- 素材缺失显示资源路径与替代说明；配置错误应可定位到页面 ID 和字段。
- 动画中快速翻页、返回目录、全屏切换和调整窗口后，当前页与选中章保持一致，不出现死锁。
- 保存原型时不得让历史主题或占位章节混入新的学术样稿。
