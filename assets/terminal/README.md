# Terminal Recordings

Store self-recorded or clearly licensed Asciinema `.cast` files in `recordings/`.

Each recording should keep a small note with:

- purpose and expected playback length;
- source command or project;
- recording date;
- license or permission source;
- whether it is safe to publish in a public HTML demo.

Pi's terminal screenshots and interaction analysis belong in `references/patterns/terminal/`, not here.
